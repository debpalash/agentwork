# Collagent campaign artwork

Open `collagent-campaign.html` in a browser. The artwork is rendered entirely
with HTML5 Canvas and has four editable/exportable formats:

- 3840 × 2160 landscape
- 2400 × 2400 square
- 2160 × 2700 portrait
- 3000 × 1500 logo-system presentation

The folder also includes `collagent-platform-home.png`, a 2880 × 2000
high-resolution capture of the rebranded live product.

Use the in-page **Download PNG** button, or append
`?format=landscape&export=1` for a clean browser render.
